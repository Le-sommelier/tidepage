# Security

Tidepage opens untrusted files, so reports about crashes, hangs or memory problems caused by a
crafted PDF or image are welcome, as are reports about anything that could expose a document.

Please report privately through GitHub's "Report a vulnerability" button on this repository
(Security tab), not in a public issue. Include the app version, the device and Android version, and
a file or steps that reproduce the problem.

Known findings in the hostile-input corpus are listed in `rust/pdfa-ffi/corpus/FINDINGS.md`.
